## Country Guides & German Edition

- Country Guides: [https://worthajourney.com/countries/](https://worthajourney.com/countries/) (80 national guides across 142 countries)
- German Edition: [https://worthajourney.com/de/](https://worthajourney.com/de/) ([Die 50 besten Thermen Deutschlands](https://worthajourney.com/de/thermen/), [Länderübersicht](https://worthajourney.com/de/laender/))

## Columns

| Column | Content |
| --- | --- |
| `rank` | Rank on the list, 1 to 100 |
| `name` | Venue name as printed on the list |
| `kind` | Kind of place, as printed on the list |
| `city` | City or area |
| `country` | Country |
| `country_code` | ISO 3166-1 alpha-2 |
| `latitude`, `longitude` | Position, 4 decimals |
| `url` | The venue's page on worthajourney.com |

## Load it

```python
import pandas as pd

df = pd.read_csv("https://raw.githubusercontent.com/Worth-A-Journey/worthajourney-lists/main/data/saunas-baths.csv")
```
